## Hi, I’m Miguel 👋

<img align="right" height="140" src="images/cat.gif" alt="Pixel cat wagging its tail" />

Senior Software Engineer, but more importantly, I’m someone who genuinely enjoys building things that last.

Most of my work lives in the space between **product and engineering** — turning ideas into software that feels solid, understandable, and pleasant to use. I care about code that’s easy to reason about, systems that scale without becoming fragile, and teams that can move fast without burning out.

Over the years, I’ve worked on web and mobile products across fintech, logistics, SaaS, and high-traffic platforms. I tend to gravitate toward **frontend and full-stack work**, not because it’s trendy, but because I enjoy shaping how users experience complex systems.

I value ownership, thoughtful communication, and pragmatic decisions. I like mentoring, reviewing code with context, and helping teams find simple solutions to hard problems.

Outside of work, I enjoy experimenting with side projects, refining old ideas, learning new tools at my own pace — and yes, cats are part of the equation 🐱

### Tech I work with (and why)

**Frontend**

- React & TypeScript — building predictable, maintainable UIs
- Next.js — performance, SEO, and real-world production needs
- Angular — large-scale apps and long-lived systems
- Accessibility — making sure everyone can use what we build

**Backend**

- Node.js — APIs, services, and full-stack flows
- GraphQL & REST — choosing the right tool for the job
- .NET / ASP.NET — structured backends and enterprise-grade systems
- Java & Spring Boot — robust, scalable services
- Go — performance and simplicity for high-throughput needs
- Databases — Postgres, MongoDB, Redis, and more

**Mobile**

- Flutter — cross-platform apps with strong UX
- React Native — fast iteration and product experiments
- Native iOS & Android — when performance and platform fidelity matter

**Infrastructure & Quality**

- CI/CD — automating workflows for speed and reliability
- Google Cloud Platform (GCP) — scalable, managed services
- AWS & Docker — deploying and scaling with confidence
- Testing — because shipping fast only works if things don’t break
- Figma — collaborative design and prototyping
- Clean architecture — optimizing for humans, not just machines
